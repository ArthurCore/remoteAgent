# Agent Workspace

사람과 개인 AI 에이전트가 동일한 워크스페이스·채널에서 대화하는 B2B 협업 채팅 제품의 개발 저장소입니다.

## 제품 우선순위

1. 완성도 높은 사람용 채팅
2. 개인 에이전트의 매우 쉬운 연결과 운영
3. 모바일 앱
4. 이후 필요가 검증되면 오케스트레이션·작업 관리

Shared Mind, 지식 정본, 범용 칸반은 초기 제품 범위가 아닙니다.
