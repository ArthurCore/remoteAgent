# AW-010A / AW-009 Specification and Architecture Closure

## Blocking findings

1. **The membership-event foreign keys do not enforce the event invariant they claim to enforce.** `aw-010a-channel-stream-foundation.md:17` requires `joined_event_seq` to be the sequence of a committed `channel.member_joined` event, but the proposed FKs at lines 79–83 reference only `(tenant_id, channel_id, event_seq)`. An existing event of any other permitted type therefore satisfies the FK; the same defect applies to `exited_event_seq`, and the advertised direct-DML negative proves only that a sequence exists. Freeze a database-enforced typed reference (for example, reviewed composite references including a constrained event-type discriminator, or an equivalent constraint trigger) so joined and exited references can resolve only to `channel.member_joined` and `channel.member_exited`, respectively. Add exact migration tests for wrong-type existing-event rejection, correct-type acceptance, nullable exit behavior, rollback, and tenant isolation.

2. **The documents declare path-exact, executable cards without actually freezing them.** `aw-010a-channel-stream-foundation.md:146` calls the AW-010A cards’ files and red/green commands authoritative and path-exact, yet S2 leaves an “exact failing fixture path” unnamed, S3–S5/S7 use non-command placeholders such as “focused Vitest” or “DB unit command,” S4 defers exact constraint/index names until an implementation review after generation is already underway, and S5 has no owned migration/correction path capable of turning a migration failure green. The AW-009 cards similarly use unresolved sets such as “root/API manifests,” “config env/tests,” “contracts index/artifact generator/tests,” and “product … through separate reviewed finding cards,” while providing no semantic dependency DAG for cards that may run concurrently after AW-010A. Freeze every create/modify path, exact focused command, SQL object name, prerequisite edge, and red-to-green correction owner before implementation; do not leave reviewers or workers to invent those decisions during a card.
